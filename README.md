# 🚀 برنامه مدیریت DNS پیشرفته با ElectronJS

![Electron](https://img.shields.io/badge/Electron-2B2E3A?style=for-the-badge&logo=electron&logoColor=9FEAF9)
![Node.js](https://img.shields.io/badge/Node.js-339933?style=for-the-badge&logo=nodedotjs&logoColor=white)

## ✨ ویژگی‌های کلیدی

### 🌐 مدیریت شبکه
- تشخیص خودکار تمام رابط‌های شبکه (Ethernet, Wi-Fi, VPN)
- پشتیبانی از IPv4 و IPv6
- نمایش وضعیت لحظه‌ای اتصالات

### 🔒 پروتکل‌های امنیتی
- پیکربندی DNS-over-HTTPS (DoH)
- تنظیمات DNS-over-TLS (DoT)
- اعتبارسنجی پیشرفته آدرس‌های DNS

### 🛠️ ابزارهای حرفه‌ای
- سیستم پروفایل‌های سفارشی
- بازنشانی هوشمند به DHCP
- تست سرعت و سلامت DNS
- تاریخچه کامل تغییرات

## 🏗️ ساختار پروژه

```bash
dns-manager/
├── main/                # فرآیند اصلی
│   ├── core/           # ماژول‌های اصلی
│   └── utils/          # ابزارهای کمکی
├── renderer/           # بخش رابط کاربری
│   ├── assets/         # فایل‌های استاتیک
│   ├── components/     # کامپوننت‌های Vue/React
│   └── stores/        # مدیریت حالت
├── build/              # فایل‌های ساخت
└── tests/              # تست‌های واحد و یکپارچه
```

## 🛠️ راهنمای نصب و اجرا

### پیش‌نیازها
- Node.js 16.x+
- npm 8.x+ یا yarn 1.22+
- Git (برای نصب از مخزن)

### نصب
```bash
# 1. کلون کردن مخزن
git clone https://github.com/your-username/dns-manager.git

# 2. نصب وابستگی‌ها
cd dns-manager
npm install

# 3. اجرای حالت توسعه
npm run dev
```

### اسکریپت‌های مهم
| اسکریپت | توضیحات |
|---------|---------|
| `dev`   | اجرای حالت توسعه با HMR |
| `build` | ساخت نسخه تولید |
| `pack`  | ایجاد بسته نصب |
| `test`  | اجرای تست‌ها |
